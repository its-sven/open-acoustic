# `pa-menus.js`: menu layout for the Play Acoustic Remote

`tools/pa-remote.html` builds every menu screen of the virtual front panel from `tools/pa-menus.js`. Edit that file to fix labels, value names, ranges or cell positions, then reload the page.

The file is one JavaScript line (`window.PA_MENUS = …;`) around plain JSON. That wrapper lets it load when the page is opened straight from disk. Inside the braces use JSON rules: double quotes, no trailing commas, no comments. If the file has an error, the panel status line says "Menu file problem" and the browser console names the line.

## Structure
```
window.PA_MENUS = {
  "MIX": {                       menu key; the soft buttons open VOCAL, VOCAL ADV, GUITAR, GUITAR ADV, MIX, SETUP
    "button": "MIX",             description only
    "pages": [                   sub-pages, in ◀ ▶ order
      { "title": "MIX",          title bar text (the n/N counter is added automatically)
        "showWhen": {"0x295": 0},  optional: only show this page while param 0x295 reads 0
        "rows": [                3 rows, each [left cell, right cell]; null = empty cell
          [ {cell}, {cell} ],
          [ {cell}, null ],
          [ {cell}, {cell} ] ] },
      { "title": "PRODUCT INFO", "text": ["line 1", "line 2"] },  text-only page
      { "title": "HARMONY", "layout": "image", "images": [92, 93, …], "rows": … }   picture page (Vocal/Guitar FX)
    ] }
};
```

## Cell
| Key | Meaning |
|---|---|
| `param` | Parameter ID as hex text (`"0x0BB"`). Read with SysEx `47`, set with `22`. |
| `label` | Text shown in the cell. |
| `min`, `max` | Value range the knob moves through. |
| `format` | How the value is shown: `list` (uses `values`), `dB`, `%`, `BPM`, `ms`, `Hz/2` (value ÷ 2, e.g. 880 → 440.0 Hz), `OFF/%` (0 = OFF), `number`. |
| `values` | For `list`: one name per value, starting at `min`. |
| `default` | Value shown before the pedal has been read. |

## Picture pages (`"layout": "image"`)
Vocal FX and Guitar FX pages draw like the pedal: a 92×48 picture on the left, "STYLE: <value>" along the bottom (bottom-left soft button), and a right column of three boxes for the right soft buttons: the page's other cells in order (levels as a bar), then the effect's `control` cell (OFF / ON / HIT; vocal 0x2CB–0x2D1, guitar 0x353/0x355/0x357). On these pages the `rows` positions are ignored: the first cell is the STYLE, the rest fill the right column. `images` lists one picture number per value of the page's first cell (the STYLE), starting at its `min`. The numbers refer to the firmware's image table; see `graphics/images-1.4.00/contact-sheet.png` for what each number looks like. The pictures themselves are in `tools/pa-images.js`, generated by `python3 tools/extract_images.py graphics/images-1.4.00 --js`; it holds only the pictures used by the FX pages, so a number from the contact sheet that isn't in an `images` list yet also needs adding to `pa-images.js` (rerun the script after adding it to a list there, or ask).

## `showWhen`
Some screens change with a setting. The panel reads each param named in `showWhen` from the pedal and shows only the pages whose conditions all match:
- **Mix:** `0x295` (cable in AUX IN) = 1 → AUX page, 0 → ROOMSENSE page.
- **Setup:** `0x39F` (FOOTSWITCH) = 1 → SWITCH-6 pages, 0 → SWITCH-3 pages.
- **Guitar FX:** `0x362` (BODYREZ EDITING) = 0 → basic 4 pages, 1 → full 7 pages.

## Regenerating
`python3 tools/menu_dump.py > data/menus-1.4.00.json` re-extracts the raw tables from the emulated RAM. It does **not** overwrite `pa-menus.js`, so hand edits are safe.
