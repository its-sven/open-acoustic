# TC-Helicon Play Acoustic firmware research + remote

Reverse-engineering notes, tools and data for the TC-Helicon Play Acoustic (and Play Electric) firmware, and **Play Acoustic Remote**: a browser front panel that controls a stock Play Acoustic live over USB.

> _**Unofficial** community project. Not affiliated with, endorsed by, or supported by TC-Helicon / Music Tribe. "Play Acoustic", "Play Electric" and "TC-Helicon" are trademarks of their respective owner, used here only descriptively. No proprietary firmware binaries or disassembly are distributed in this repository. Use at your own risk._

- **Remote:** `tools/pa-remote.html` (how to use it: `tools/README.md`)
- **Verify checklist:** `tools/verify.html`, an interactive list of what has been tested on the unit and what still needs checking
- **Write-up:** `docs/index.html` (rendered overview), `docs/ANALYSIS.md` (detailed notes), `docs/SYSEX.md` (SysEx reference), `docs/MENUS.md` (menu layout)
- **To-dos and ideas:** `TODO.md`

> **Safety**
> - Never change **MIDI CTRL (0x278)** or **FILTER (0x27B)**. Either can make the pedal ignore USB SysEx after the next power-up, and there is no MIDI socket to undo it. The remote refuses both.
> - **Factory reset** = hold **STORE + BACK** while powering on. It erases settings **and your presets/favorites**.
> - Close **VoiceSupport** while using the remote (it corrupts incoming SysEx).
> - The stock `.syx` files in `stock/` are read-only recovery images. Read `docs/ANALYSIS.md` §5 before flashing anything.

## Layout
| Path | What |
|---|---|
| `tools/pa-remote.html` | Play Acoustic Remote (Chrome/Edge, Web MIDI + SysEx): virtual front panel, live parameter control (SysEx `22`/`47`), MIDI monitor |
| `tools/pa-menus.js` | Editable menu layout for the remote (JSON; format in `tools/MENUS-FORMAT.md`) |
| `tools/pa-images.js` | Display pictures for the remote's FX pages (generated by `tools/extract_images.py --js`) |
| `tools/verify.html` | Interactive verify/to-do checklist (state saved in the browser, export/import as JSON) |
| `tools/` | `tch_unpack.py` (.syx → sections), `hi08_records.py` (sections → load records), `dump_params.py` (parameter descriptors from RAM), `menu_dump.py` (menus + value names from RAM), `extract_images.py` (display images), `render_columns.py` (raw bitmap renderer) |
| `tools/emulator/` | `emu_harness.cpp`: boots the image in the dsp56300 emulator and dumps RAM (`docs/ANALYSIS.md` §10) |
| `tools/exploration/` | One-off analysis scripts (code-density map, build diff) |
| `stock/oddeyez/` | The 7 firmware images as served by oddeyez.se, plus `manifest.json` and `SHA256SUMS`. **Read-only recovery copies.** |
| `stock/official/` | PA 1.2.00 and 1.3.00 from the official TC-Helicon VoiceSupport2 server (byte-identical to the oddeyez copies) + `SHA256SUMS` |
| `data/sections/` | Decoded `sec0` (loader) / `sec1` (main image) for all 7 builds |
| `data/records-1.4.00/` | The 12 load records of 1.4.00 (`rNN_<P|X>_<load address>.bin`) |
| `data/` | `params-1.4.00.csv` (all 948 parameter IDs: names, ranges, value names, settable), `menus-1.4.00.json` (raw menu tables), `strings-1.4.00-24bit.txt`, `params-1.4.00-raw.txt`, `ui-map-1.4.00.csv` (first-pass menu map, IDs ≤ 0x2BF only; superseded by `menus-1.4.00.json`) |
| `disasm/1.4.00/` | DSP56300 disassembly of every record + `sec0_loader.asm` + `strings_addr.txt` |
| `emulation/1.4.00/` | Emulated RAM dumps after boot + run log |
| `graphics/` | `images-1.4.00/`: all 146 display images (PNG each, `index.json`, `contact-sheet.png`); raw font/bitmap renders |
| `docs/` | `index.html`, `ANALYSIS.md`, `SYSEX.md`, `MENUS.md`, `img/` |
| `legacy/cc-approach/` | The abandoned MIDI CC approach: CCtest1 patched image, CC-map patcher, notes (`README.md` there) |
| `legacy/v1/`, `legacy/tools/` | Superseded first-pass analysis (wrong decode) and old scripts |

## Quick start (firmware analysis)
```bash
python3 tools/tch_unpack.py "stock/oddeyez/PlayAcoustic 1.4.00 Build51.syx" data/sections
python3 tools/hi08_records.py data/sections/PlayAcoustic_1.4.00_Build51.sec1.bin -x data/records-1.4.00
python3 tools/menu_dump.py > data/menus-1.4.00.json
python3 tools/extract_images.py graphics/images-1.4.00 --js
```
